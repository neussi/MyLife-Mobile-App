Présentation du projet

1.1

Objectif

MyLife est une application mobile tout-en-un permettant de gérer l’ensemble des aspects de
la vie quotidienne : planning, finances, contacts, projets et suivi d’activités avec bilan journalier
complet.

1.2

Technologies

— Frontend : Flutter (iOS/Android)
— Backend : Django REST Framework
— Base de données : Firebase + SQLite (local)
— Authentification : Firebase Authentication

1.3

Charte graphique

— Couleur principale : Blanc
— Couleur secondaire : Bleu ciel (#87CEEB)
— Couleur accent : Orange (#FF8C00)

2

Modules fonctionnels

2.1

Module Authentification

— Inscription (email/mot de passe)
— Connexion sécurisée
— Réinitialisation de mot de passe
— Authentification biométrique (empreinte/Face ID)
— Gestion de profil utilisateur

2.2

Module Planning & Agenda

— Calendrier intégré (vue jour/semaine/mois)
— Création d’événements et rendez-vous
— Gestion des tâches quotidiennes
— Programmation d’activités récurrentes
— Notifications de rappel configurables
— Cocher les tâches réalisées
— Bilan de journée automatique et complet

2.3

Module Prise de notes

— Notes textuelles avec éditeur riche
— Notes vocales (enregistrement audio)
— Notes vidéo
— Notes avec images (galerie/appareil photo)
— Catégorisation et tags
— Recherche dans les notes
— Synchronisation cloud

2.4

Module Gestion financière

— Enregistrement des entrées d’argent
— Enregistrement des sorties/dépenses
— Catégorisation des transactions
— Calcul automatique du solde financier
— Bilans financiers :

— Hebdomadaire
— Mensuel

— Graphiques et courbes d’évolution budgétaire

Module Contacts & Relations

— Enregistrement de contacts
— Gestion des rencontres
— Suivi des vœux et occasions spéciales
— Historique des interactions
— Notes associées aux contacts (texte/audio/vidéo)

2.6

Module Projets & Rapports

— Création et gestion de projets
— Définition d’objectifs
— Suivi de progression
— Jalons et échéances
— Rapports de projet (texte/audio/vidéo)
— Partage de rapports

2.7

Module Notifications

— Notifications push sérieuses et cohérentes
— Rappels d’événements programmés
— Alertes de tâches
— Notification de bilan de journée
— Configuration personnalisée des alertes

Fonctionnalités avancées

— Dashboard personnalisé : Vue d’ensemble avec widgets configurables
— Bilan journalier complet : Résumé automatique des tâches, finances, événements
— Mode sombre/clair : Adaptation automatique
— Synchronisation multi-appareils : Via Firebase
— Sauvegarde automatique : Locale (SQLite) et cloud (Firebase)
— Recherche globale : Tous contenus (notes, tâches, finances, projets)
— Export de données : PDF, CSV, Excel
— Widgets système : Accès rapide depuis l’écran d’accueil
— Mode hors-ligne : SQLite pour fonctionnement sans connexion
— Statistiques d’utilisation : Productivité et habitudes
— Rappels intelligents : Suggestions basées sur l’historique
— Analyse de tendances : Évolution des finances et productivité
— Templates personnalisables : Pour notes, projets et rapports

4

Architecture technique

4.1

Backend (Django)

— API REST avec Django REST Framework
— Authentification JWT + Firebase
— Modèles de données pour chaque module
— Endpoints CRUD pour toutes les entités
— Gestion des fichiers médias (audio/vidéo/images)
— Calculs automatiques (bilans financiers, statistiques)
— Système de génération de rapports

4.2

Frontend (Flutter)

— Architecture Clean Architecture
— State management (Bloc/Riverpod)
— SQLite pour cache local
— Firebase pour synchronisation temps réel
— Lecteur audio/vidéo intégré
— Composants UI réutilisables
— Gestion des permissions (caméra, micro, stockage)
— Interface responsive et fluide

4.3

Base de données

— Firebase Firestore : Données cloud synchronisées
— SQLite : Cache local et mode hors-ligne
— Schéma relationnel pour :
— Utilisateurs et profils
4

— Événements et tâches
— Notes (avec références médias)
— Transactions financières
— Contacts et rencontres
— Projets et rapports
— Bilans quotidiens

5

Exigences non fonctionnelles

— Performance : Temps de chargement < 2 secondes
— Sécurité : Chiffrement des données sensibles (AES-256)
— Scalabilité : Support de milliers d’entrées par utilisateur
— Disponibilité : 99% uptime pour le backend
— Compatibilité : iOS 12+ et Android 8+
— Interface : Design cohérent respectant la charte graphique
— Accessibilité : Support des lecteurs d’écran
— Langues : Français (extensible à d’autres langues)
